### Research

**[Assessing opportunities for enhanced lighting energy conservation via occupancy and daylight monitoring](https://www.sciencedirect.com/science/article/pii/S2950345024000150)**  
*Measurement: Energy*, 2024. Computer vision on indoor CCTV to judge whether lighting use is efficient, wasteful, or neutral. YOLO models detect people, lights, and windows at 94.9%, 73.3%, and 98.7%.

### Selected work

**PennOS** — Unix-like operating system in C. Preemptive priority scheduler, FAT-style file system, and a shell with jobs, pipes, and redirection.

**[RescueSim](https://github.com/shreyakhetan09/World-Models-Hack)** — disaster-rescue agent inside a live world model. Gemini Robotics plans each step; hearing and imagined-route search locate survivors.

**[Podcast Agent](https://github.com/shreyakhetan09/PodcastAgent)** — Google ADK agent that ingests podcast feeds, transcribes them with Whisper, and writes a structured briefing.

**[Developer Knowledge RAG](https://github.com/shreyakhetan09/Developer-Knowledge-RAG)** — syntax-aware retrieval over a multi-repo codebase. Tree-sitter chunking, Chroma, and Gemini return citation-backed answers.

**[LLM Emotion Finetuning](https://github.com/shreyakhetan09/LLM-Emotion-Finetuning)** — LoRA fine-tune of a 1.1B model on one GPU. About 0.2% of the weights are trained to steer behavior.

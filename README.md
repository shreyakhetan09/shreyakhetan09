### Selected Work

- **[Developer Knowledge RAG](https://github.com/shreyakhetan09/Developer-Knowledge-RAG)** — syntax-aware retrieval over a multi-repo GitHub organization. Tree-sitter chunking, Chroma, and Gemini return citation-backed answers for onboarding and incident triage.
- **[LLM Emotion Finetuning](https://github.com/shreyakhetan09/LLM-Emotion-Finetuning)** — LoRA fine-tune of a 1.1B model on one GPU, training about 0.2% of the weights to steer model behavior.
- **[Podcast Agent](https://github.com/shreyakhetan09/PodcastAgent)** — Google ADK pipeline that ingests podcast RSS feeds, transcribes them with Whisper, and writes a structured briefing.
- **[People detection with YOLO and OpenCV](https://github.com/shreyakhetan09/Detecting-People-Using-YOLO-and-OpenCV)** — detection pipeline for counting people in a scene.
- **PennOS** — Unix-like operating system in C, with a preemptive priority scheduler, a FAT-style file system, and a shell that supports jobs, pipes, and redirection.
- **Daylight-driven energy conservation** — computer-vision framework for lighting and occupancy in smart buildings, using YOLOv8. Published in Elsevier *Measurements: Energy*.
